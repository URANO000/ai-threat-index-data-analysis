## Q
### What datasets are you using?
We are using two datasets to analyze the threat index and exposure per profession in relation to AI displacement.
https://www.meritforgeai.com/data/ai-career-threatindex/ 
https://www.anthropic.com/research/labor-marketimpacts 

### What packages do I need to run this?
Please install pandas, matplotlib, scikit-learn and numpy using pip install in your terminal.
